What a module can contain

Characters (sprites, animations, backdrops, temperament) and sub-programs. A sub-program can be a described layout, or real bytecode — branching, arithmetic, its own state, and buttons that do things. It runs in a sandboxed VM: no raw memory access, every jump and index checked before it loads, and an instruction budget so a loaded page cannot hang the device.

Installed on device

Connect to read the device.

Bluetooth: the radio is off until you open UPDATE on the pet's own menu. Leaving that page turns it off again, so the device is not discoverable while it is just being a pet.

Removing a module deletes its characters. If the pet currently is one of them, the device starts a new pet from whatever remains.
